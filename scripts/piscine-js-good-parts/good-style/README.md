# Good Style

## Philosophie

Un bon style n'est pas juste esthétique - il prévient les bugs, améliore la lisibilité et facilite la maintenance.

## Principes fondamentaux

1. **Clarté > Concision** - Code lisible plutôt que malin
2. **Cohérence** - Même style partout dans le projet
3. **Noms significatifs** - Variables et fonctions auto-documentées
4. **Petites fonctions** - Une fonction = une responsabilité
5. **Éviter les effets de bord** - Préférer l'immutabilité

## Outils

- **ESLint** - Détection de problèmes
- **Prettier** - Formatage automatique
- **TypeScript** - Typage statique
