# Good Syntax

## Objectif
Maîtriser les bonnes pratiques syntaxiques de JavaScript selon Douglas Crockford.

## Exercices

- **ex00** - Strict Equality : `===` vs `==`
- **ex01** - Declarations : `const`, `let`, éviter `var`
- **ex02** - Truthy & Falsy : Comprendre les valeurs "falsy"
- **ex03** - Guard Expressions : `&&` et `||` pour le contrôle de flux
- **ex04** - Object & Array Literals : La bonne façon de créer des structures

## Règles de Crockford

1. **Toujours utiliser `===` et `!==`** - Évite les surprises de coercion
2. **Déclarer les variables en haut du scope** - Clarté et prévisibilité
3. **Un seul `var`/`let`/`const` par déclaration** - Lisibilité
4. **Toujours utiliser les accolades** - Même pour une seule ligne
5. **Placer l'accolade ouvrante sur la même ligne** - Évite les pièges ASI
