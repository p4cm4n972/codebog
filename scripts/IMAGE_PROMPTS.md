- **Midjourney** : Meilleur pour le style game art cohérent
- **DALL-E 3** : Bon pour les icônes détaillées
- **Stable Diffusion** : Contrôle précis avec ControlNet

## Paramètres Midjourney Suggérés
```
--ar 4.8:1 --v 6 --style raw    # Pour bannières
--ar 3:2 --v 6 --style raw      # Pour cartes
--ar 1:1 --v 6 --style raw      # Pour icônes
```

## Post-Traitement
1. Upscale à la résolution cible
2. Ajuster les couleurs pour cohérence de palette
3. Ajouter transparence pour icônes (supprimer fond)
4. Optimiser pour web (WebP pour bannières/cartes, PNG pour icônes)
