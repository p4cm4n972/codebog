# Ex00 - Hello JavaScript

## Objectif
Faire tes premiers pas en JavaScript et comprendre la syntaxe de base.

## Contexte
JavaScript est le langage du web. Avant de plonger dans les concepts avancés, il faut maîtriser les bases : retourner des valeurs, faire des opérations simples, et utiliser `typeof`.

## Instructions

Complète les 4 fonctions pour qu'elles retournent les bonnes valeurs :

### `helloWorld()`
Retourne la chaîne de caractères `"Hello, World!"`

### `addNumbers()`
Retourne le résultat de l'addition `40 + 2`

### `concatenate()`
Retourne la concaténation de `"Hello"`, `" "` et `"JavaScript"` (avec l'opérateur `+`)

### `whatIsThis()`
Retourne le type de la valeur `"hello"` (utilise `typeof`)

## Exemple
```javascript
helloWorld();    // "Hello, World!"
addNumbers();    // 42
concatenate();   // "Hello JavaScript"
whatIsThis();    // "string"
```
